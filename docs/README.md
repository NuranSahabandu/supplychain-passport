# Software Engineer Internship — Mini Project Assignment

**Project:** SupplyChain Passport — Product Traceability, Compliance & Digital Product Passport (DPP)

**Suggested duration:** 5–7 days (approximately 12–18 hours of work).  
**Recommended stack:** Laravel REST API, Vue.js, MySQL. Candidates may propose an equivalent stack.  
**Submission:** Git repository link, setup instructions, screenshots, and a short demonstration video (3–5 minutes).  
**Total marks:** 100.

## Objective
Build a small web application that lets a company register a product, record its supply-chain journey, manage compliance certifications, and publish a customer-facing Digital Product Passport.

## Start here
1. Read `brief/01-problem-statement.md` and `brief/02-user-scenarios.md`.
2. Follow `requirements/01-functional-requirements.md` and `requirements/02-technical-and-acceptance.md`.
3. Use `design/01-colour-palette-and-ui.md` and the sample JSON/CSV in `data/`.
4. Check `evaluation/01-marking-rubric.md` and `submission/01-submission-guide.md`.

## Scope and fairness
This is an internship assessment, not a production-grade platform. The **must-have** requirements determine the core score. Bonus features are optional; do not sacrifice quality of core functionality for extras. No paid services or actual certification authority integrations are required.
