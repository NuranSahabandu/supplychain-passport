# Candidate Submission Guide

## Deliverables
1. **Git repository URL** with the complete source code and readable commit history.
2. **README.md** explaining prerequisites, installation commands, environment configuration, database setup, seeding, how to run backend/frontend, and any demo login details.
3. **Sample data** matching or inspired by `data/sample-product.json`.
4. **Screenshots** of product list, product detail, supply chain, certifications, and public DPP.
5. **3–5 minute demo video** showing product creation, certificate states, publish → edit → republish flow, and mobile view.
6. **Short notes** describing architecture decisions, limitations, and any AI tools used.

## Suggested work plan
- Day 1: data model, migrations, basic API.
- Day 2: product and supplier screens.
- Day 3: supply-chain stages and certifications.
- Day 4: public DPP and publish snapshot.
- Day 5: responsive styling, testing, documentation, demo.

## Rules
- Original implementation; third-party packages and AI assistance are allowed if disclosed.
- Candidate must understand and explain submitted code.
- Use fictional data only; do not upload real personal or confidential supplier information.
- No paid services are required.
- Clearly document anything not completed.
